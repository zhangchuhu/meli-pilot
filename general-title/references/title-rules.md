# Mercado Libre México title rules

Use the formula matching the product. Omit any unsupported slot rather than guessing.

## Shared ordering

`core category + silhouette/length + components + design feature + audience + style/occasion + owned brand/model`

Keep the core category early. Strong searchable nouns and concrete features outrank vague claims such as `bonito`, `premium`, or `de moda`.

## 1. Dresses

Formula:

`Vestido + Largo/Corto/Midi + feature + Mujer/Dama + Casual/Elegante/Fiesta + owned brand/model`

Useful supported features include `Abertura`, `Sin Mangas`, `Espalda Abierta`, `Tirantes`, `Escote V`, and `Estampado Floral`.

Example pattern: `Vestido Largo Con Abertura Para Mujer Elegante De Fiesta`

## 2. Women's skirt sets

Formula:

`Conjunto + Top/Blusa + Y Falda + length/cut + Mujer/Dama + style/occasion + owned brand/model`

State the piece count when known: `2 Piezas` or `3 Piezas`. Useful skirt terms include `Corta`, `Midi`, `Larga`, `Plisada`, and `Ajustada`.

Example pattern: `Conjunto De 2 Piezas Mujer Top Y Falda Midi Elegante`

## 3. Women's pants sets

Formula:

`Conjunto + piece count + upper component + Y Pantalón/Palazzo + Mujer/Dama + cut + style/occasion`

Upper components include `Top`, `Blusa`, `Camisa`, `Camisola`, `Chaleco`, and `Blazer`. Pants terms include `Palazzo`, `Recto`, `Corto`, `Acampanado`, and `Tiro Alto`.

Example pattern: `Conjunto De 2 Piezas Mujer Blusa Y Pantalón Palazzo Casual`

## 4. Women's vest sets

Formula:

`Conjunto/Traje + 2 Piezas + Chaleco + Y Pantalón/Palazzo/Short + Mujer + cut + style/occasion`

Use `Chaleco` explicitly. Supported feature terms may include `Blazer`, `Abotonado`, `Sin Mangas`, `Cuello V`, and `Talle Alto`.

Example pattern: `Conjunto De 2 Piezas Mujer Chaleco Y Pantalón Palazzo Elegante`

## 5. Women's formal gowns

Formula:

`Vestido + Largo/Corto + De Gala/Fiesta/Noche/Cóctel + Mujer + material/neckline + focal feature + Elegante/Formal`

Use materials only when visible or stated: `Satén`, `Encaje`, `Lentejuela`, `Malla`, or `Tul`. Useful design terms include `Corset`, `Escote Cruzado`, `Cuello V`, `Abertura`, and `Espalda Abierta`.

Example pattern: `Vestido Largo De Gala Para Mujer Con Escote V Y Abertura`

## Variation plan for 10 titles

Create genuine search-intent variation:

1. Category-first canonical title.
2. Silhouette or length emphasis.
3. Main design-feature emphasis.
4. Occasion emphasis.
5. Component emphasis for sets.
6. Secondary supported feature emphasis.
7. Audience-first phrasing after the category.
8. Style emphasis.
9. Concise high-intent version.
10. Broad synonym coverage without repetition.
